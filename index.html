Résoudre une équation (1 inconnue)

Saisissez une équation en x. Exemple : 2x + 3 = 7, x^2 - 5x + 6 = 0, sin(x) = 0.5.

Fonctions : sin, cos, tan, exp, log, sqrt • Puissance : ^
Conseil : si votre équation est polynomiale, pensez à réduire/normaliser avant. Pour les fonctions générales, on utilise une recherche par intervalles avec bissection.
